# 📊 Retirement Financial Planning Tool

ระบบจำลองแผนการเงินหลังเกษียณและการทดสอบความเสี่ยงแบบ Interactive (Monte Carlo & SORR Analysis) พัฒนาขึ้นเพื่อช่วยประเมินความเพียงพอของเงินออมและการบริหารความเสี่ยงในระยะยาว รองรับการใช้งานทั้งภาษาไทยและภาษาอังกฤษ

## ✨ Key Features (ฟีเจอร์เด่น)
* **Interactive Simulation:** ปรับแต่งข้อมูลอายุปัจจุบัน, อัตราผลตอบแทน และแผนรายรับ-รายจ่ายได้แบบเรียลไทม์
* **Risk Analysis:** จำลองสถานการณ์ความเสี่ยงด้วยวิธี Monte Carlo และทดสอบผลกระทบช่วงต้นของการเกษียณ (Sequence of Returns Risk - SORR)
* **Visualized Charts:** แสดงผลกราฟจำลองสถานการณ์ความเสี่ยงรายปีด้วย Chart.js เพื่อความเข้าใจง่าย
* **Bilingual Support:** รองรับการสลับภาษา (TH / EN)

## 🛠️ Technology Stack
* **HTML5 & JavaScript**
* **Tailwind CSS** (สำหรับตกแต่งส่วนติดต่อผู้ใช้งาน)
* **Chart.js** (สำหรับแสดงกราฟสถิติและการจำลอง)
* **Font Awesome & Google Fonts** (Prompt / Sarabun)
